# User Guide

1. Open the AgricultureGPT dashboard.
2. Enter an agricultural question.
3. Review the evidence status and any citations.
4. Treat AI-generated advice as advisory, not a verified diagnosis.
5. Consult an appropriately qualified local expert for pesticides, chemicals,
   dosage, disease diagnosis or high-impact farm decisions.
6. Do not submit passwords, API keys or unnecessary personal identifiers.
