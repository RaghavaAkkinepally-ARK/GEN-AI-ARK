# Project Overview

AgricultureGPT combines a provider-agnostic LLM client, prompt and tool controls,
retrieval from agricultural sources, optional QLoRA-adapted inference, and a
farmer-facing application.

The implementation is evidence-oriented: experiments record inputs, metrics,
configuration and limitations without claiming measured success before execution.

## Phase plan

1. Repository and architecture
2. CO1 provider abstraction and tokenization
3. CO2 transformer and decoding experiments
4. CO3 cited RAG
5. CO4 prompt, tools and security
6. CO5 QLoRA, common-held-out-set comparison and router
7. CO6 full-stack application
8. Deployment and governance
9. Documentation and final traceability
